Projects I've Brought to Life

A short walk through three sites I've built, from early practice pages to a full professional build.

Project 01

TasteBuds Café

A basic HTML and CSS landing page built to practice core layout skills: a styled navigation bar, a hero section with a call-to-action button, and a three-column card layout built with flexbox. My first project coded fully from a blank page.

Project 02

Wanderlust Travel Blog

A simple travel and photography blog focused on CSS Grid. I used it to practice arranging an image gallery, spacing content evenly, and adding hover effects that make each tile feel interactive without any JavaScript.

Project 03

Black Pebble Inc.

A professional, client-style business website with a more advanced front-end build: a consistent brand header, a hero section with clear messaging and a call to action, and structured service cards. This project pushed me to think about layout, hierarchy, and polish the way a real client site demands.
