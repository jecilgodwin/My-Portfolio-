The Skills Behind the Screen

Front-End Development

This is where I'm most at home. I build page structure with semantic HTML, then shape it with CSS, working with flexbox and grid to lay out sections, styling buttons and navigation with hover states and transitions, and making sure a layout still holds together on a smaller screen. I care about the small details, spacing, alignment, consistent color use, because they're what separate a page that looks finished from one that just looks coded.

HTML5 CSS3 Flexbox & Grid JavaScript Responsive Design

Back-End Development

Beyond what's visible in the browser, I'm learning how a site actually works behind the scenes: how a server receives a request, runs logic, and sends back a response. I'm building an understanding of routing, handling form data, and connecting front-end pages to the logic that powers them, so that a website isn't just something to look at, but something that actually does things.

Node.js Basics PHP Fundamentals APIs & Routing Server Logic

Databases

I'm also getting comfortable with how information is stored and organized so an application can actually remember things. That means understanding tables, relationships, and basic queries, thinking through how data like a user's details or a form submission should be structured before it's ever saved. It's less visible than front-end work, but it's the part that makes a site feel like a real application instead of a static page.

MySQL MongoDB Basics Database Design CRUD Operations
